### Фаза 1. Механизм drawing defaults (высший приоритет)

**Дефект:** парсер везде передаёт `0UL` как defaults mask и пишет значение ордера в бандл дословно, включая X'00'.

**Основание:** EDM2 `GpiSetAttrs` — `flDefMask`; ошибки `PMERR_INV_COLOR_ATTR`, `PMERR_INV_MIX_ATTR`, `PMERR_INV_LINE_WIDTH_ATTR`, `PMERR_INV_LINE_TYPE_ATTR`, `PMERR_INV_CHAR_SET_ATTR`, `PMERR_INV_CHAR_MODE_ATTR`, `PMERR_INV_CHAR_DIRECTION_ATTR`, `PMERR_INV_CHAR_SHEAR_ATTR`, `PMERR_INV_CHAR_ANGLE_ATTR`, `PMERR_INV_MARKER_SET_ATTR`, `PMERR_INV_MARKER_SYMBOL_ATTR`, `PMERR_INV_PATTERN_SET_ATTR`, `PMERR_INV_PATTERN_ATTR`, `PMERR_INV_BACKGROUND_COL_ATTR` — все с формулировкой «or the default value was explicitly specified with GpiSetAttrs instead of using the defaults mask».

| № | Работа |
|---|---|
| 1.1 | Хелпер установки атрибута: X'00' → `flAttrMask = flDefMask = mask`; иначе значение в бандле, `flDefMask = 0` |
| 1.2 | Применить ко всем Set-обработчикам и к GPOP |
| 1.3 | Снять ручное разрешение default в `DoSetCharCell` (вызов `GreGetDefaultAttributes` + подстановка числа) |

### Фаза 3. Стек атрибутов

Установлено (GDDM SC33-0868-02 §10.6.4, §10.7.37; EDM2 GpiPop/GpiSetAttrMode/GpiSetColor):

- Push-and-Set и Pop — полный GOCA, не расширение PM;
- Push кладёт **текущее** значение, Pop снимает **одну** запись;
- второй байт GPOP — `X'00'`, зарезервирован; `GpiPop(hps, n)` порождает **n ордеров** X'3F';
- shorthand сохраняется/восстанавливается **одной** записью («restored by a single GpiPop function»);
- стек единый: атрибуты, current position, arc parameters, model transform, tag;
- defaults инвариантны внутри drawing process (AFPC p. 79) → на стек не кладутся;
- chained-сегмент отбрасывает остаток стека на конце; called-сегмент восстанавливает всё сохранённое автоматически.

| № | Работа |
|---|---|
| 3.1 | Запись стека: маски по пяти примитивам + виды для не-бандлового состояния (CP, arc params, transform, tag, stroke line width). Одна запись = один push-ордер |
| 3.2 | Хелперы Push/Pop; Pop восстанавливает и признак «= default», и значение |
| 3.3 | Диспетчеризация: 21 push-ордер проваливанием в парный Set; `GPOP` — снятие одной записи с проверкой `p[1] == 0` |
| 3.4 | Границы сегментов: сброс глубины для chained, авто-восстановление для called |
| 3.5 | Ограничение Pop внутри области/пути (AFPC p. 38; EDM2 GpiPop) |

### Требует подтверждения до кода

1. Лимит глубины стека (EC-0005) — ни в AFPC, ни в GDDM, ни в EDM2 не задан.
2. Реакция на Pop из пустого стека: в PM это `PMERR_SEG_CALL_STACK_EMPTY (0x20FC)`, в `F_gocaerr.h` архитектурного EC нет.
3. Getter арк-параметров из DC — по `pmddim.h`; при отсутствии — инициализация стандартными значениями AFP (p. 25: P=Q=1, R=S=0).
4. Перенос правила «одна запись на shorthand-ордер» с GPSICOL на GPSCOL/GPSMX/GPSBMX — прямое доказательство получено только для `GpiSetColor`.
5. Взаимодействие стека Push/Pop с элементами `GBEL`/`GEEL` (`ETYPE_*BUNDLE`) — один стек или два.
