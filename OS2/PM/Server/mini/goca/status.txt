# Аудит и план работ GOCA-парсера

Диалект: **FULL GOCA (PM)**. Поддерживаются все варианты coordSize (BYTE, SHORT, LONG), BE/LE.
AFPC-0008-03 — ПОДМНОЖЕСТВО FULL GOCA, только BE/SHORT.
GDDM SC33-0868 — подмножество FULL GOCA, только BYTE/SHORT, BE.
Контракт движка — EDM2 (Gre*); макросы — pmddim.h; коды приказов и структуры — pmord.h.

## A. Смешанный контракт GRE — **ЗАВЕРШЕНО**

Все атрибутные вызовы на движковом уровне (`GreSetAttributes`/`GreGetAttributes`) с голыми бандлами. `GreDevice*Attributes` в `goca_parser.cpp` отсутствуют.

**Правило установки drawing default (EDM2 `GreSetAttributes`):**
> «Attributes whose flags are set in **both** flDefsMask and flAttrsMask are set to their default values.»
> «Attributes whose flags are set **only in flDefsMask** … are unchanged.»
> «Attributes whose flags are set only in flAttrsMask are set to the value specified by pAttrs.»

Следствие: бит дефолта обязан присутствовать одновременно в третьем и четвёртом аргументах.

**A2 (опционально).** `#define INCL_DDIBUNDLES` в `goca_parser.hpp` можно удалить.

---

## B. Возврат `GreGetAttributes` — **ЗАВЕРШЕНО**

`GocaPushAttr`: `lDefs = GreGetAttributes(...)`, `e->usXxxDefs = (lDefs == GPI_ALTERROR) ? 0 : (USHORT)(lDefs & usXxx)`.
`GocaPop`: третий аргумент = `(ULONG)e->usXxxDefs`, четвёртый = `(ULONG)e->usXxx`. Для атрибутов, бывших = default, движок подставит актуальный default сам.

### C3–C5. Текущая позиция — **НЕ ВЫПОЛНЕНО**

| Ордер | Дефект | Основание |
|---|---|---|
| **GCCHST (0x83)** | `GreSetCurrentPosition` вызывается безусловно после ветвления | AFPC p. 92: CP **unchanged** |

### C6. Пустые и минимальные операнды (маркеры) — **ЗАВЕРШЕНО**

`DoMark`: `GrePolyMarker(c->hdc, &aptl[bGiven], (LONG)(nPts+1))`. Для GMRK 1 точка рисуется 1 маркер в P0; для GCMRK `len==0` рисуется 1 маркер в CP.

### C7–C13. Пустые и минимальные операнды (линии/кривые) — **НЕ ВЫПОЛНЕНО**

| Ордер | Сейчас | Должно | Статус |
|---|---|---|---|
| **GCLINE** `len==0` | `GrePolyLine(...,0)` — No-Op | No-Op | ✓ |
| **GLINE** `len==pointSize` | `GreSetCurrentPosition` + `nPts--`→0 | только переместить CP | ✓ |
| **GCRLINE** `len==0` | EC-0003 | No-Op | ✗ |
| **GRLINE** `len==pointSize` | `GrePolyLine(aptl,1)` — линия из 1 точки | только переместить CP | ✗ |
| **GCCBEZ** `len==0` | EC-0003 | No-Op | ✗ |
| **GCBEZ** 1 точка | `GrePolySpline(aptl,2)` | только переместить CP | ✗ |
| **GBEZ** 1 точка | `len < 2*pointSize` → EC-0003 | только переместить CP | ✗ |
| **GCFLT** `len==0` | EC-0003 | No-Op | ✗ |
| **GFLT** 1 точка | `len < 2*pointSize` → EC-0003 | только переместить CP | ✗ |
| **GCBEZ/GCCBEZ** | нет проверки 3m+1 | EC-0003 | ✗ |

### C15. Логическая против геометрической ширины линии — **ЗАВЕРШЕНО**

`GSLW`/`GSFLW`: только `lb.fxWidth`, маска `LBB_WIDTH`. `lGeomWidth` удалён. Геометрическая ширина — отдельный атрибут `GSSLW` (0x15), не реализован (D10).

### C16. GSMC: условие нулевой ячейки — **ЗАВЕРШЕНО**

`bZero = (cx == 0 || cy == 0)`; при drawing default `flDefsMask = MBB_BOX`; при literal zero — принудительное обнуление обеих компонент.

### C17. GSPRP при DEFAULT — **НЕ ВЫПОЛНЕНО**

При `GSPRP_DEFAULT` жёстко `pt.x=0; pt.y=0`, `GreSetAttributes(..., 0UL, ABB_REF_POINT, ...)`. Должно быть `flDefsMask = ABB_REF_POINT` в обеих масках, поле не заполнять.

### C18. GSCC default без индирекции — **НЕ ВЫПОЛНЕНО**

`GreGetDefaultAttributes(c->hdc, PRIM_CHAR, CBB_BOX, &cbDef)` + `bun.sizfxCell = cbDef.sizfxCell` + `GreSetAttributes(..., 0UL, CBB_BOX, ...)`. Фиксирует снимок дефолта. Должно быть `flDefsMask = CBB_BOX`, вызов `GreGetDefaultAttributes` удалить.

### C19. Таблица цветов GOCA ≠ GPI — **НЕ ВЫПОЛНЕНО**

| Значение | Сейчас | Требуется |
|---|---|---|
| 0000 / FF00 | дословно в бандл | `flDefsMask` |
| 0007 | 7 | `CLR_WHITE` (−2) |
| 0008 | 8 | `CLR_BLACK` (−1) |
| FF07 | 7 | `CLR_NEUTRAL` |
| FF08 | 8 | `CLR_BACKGROUND` (0) |
| 000A, 000B, 000E, 000F, 0010 | нет констант | решение 1 |

**GSCOL байт 0x07 ≠ GSECOL 0x0007.** Первый → FF07 (device default), второй → White. Код обрабатывает одинаково.

## Решения, нужные до кода

1. **Цвета без констант GPI** (Orange 0x000A, Purple 0x000B, Mustard 0x000E, Gray 0x000F, Brown 0x0010): RGB-режим логической таблицы (`GreCreateLogColorTable`, `LCOLF_RGB`), ближайший индекс или собственное отображение.
2. **`adx`** — фиксированный буфер с ограничением `cch` либо сохранение `DosAllocMem`.
3. **`DoBox`** — флаги PM (0x40/0x20) против AFP RES=X'2000': разделение по диалекту или единая трактовка. Поведение при сброшенных обоих битах.
4. **`GBOX` CP** — контракт `GreBox*` по CP из `pmddim.h`: `GreBox*` использует CP как первый угол. Для GBOX CP устанавливается в (XPOS0, YPOS0) до вызова. Для GCBOX CP уже на месте — не трогать.
5. **`GCHSTE` при `cch==0`** — зафиксировано: ранний возврат до DRAWRECT/LEAVEPOS. Если DRAWRECT при пустой строке должен рисовать рамку — вернуться к пункту.
6. **EC-0002** — репортировать (PM) или игнорировать (AFP 4-я ред., retired). `GocaEcIsRetired` в `F_gocaerr.h` существует, но парсер его не применяет.
7. **`GSCC` `bZero`** — четыре компонента через `&&` (`cxInt == 0 && cyInt == 0 && cxFrac == 0 && cyFrac == 0`). Дробная часть дополняет целую, ноль в целой при ненулевой дробной ≠ ноль ячейки. Оставить `&&` по четырём компонентам.
8. **Обводка границы дуги в области** — подчинить флагу `BOUNDARY` GBAR (AFPC p. 107) или сохранить безусловную обводку как упрощение PM.
