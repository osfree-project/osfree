Диалект: **FULL GOCA (PM)**. Поддерживаются все варианты coordsize (BYTE, SHORT, LONG), BE/LE
AFPC-0008-03 — ПОДМНОЖЕСТВО FULL GOCA, только BE/LONG
GDDM - подмножество FULL GOCA, только BYTE/SHORT, BE

## A. Смешанный контракт GRE — **ЗАВЕРШЕНО**

Все атрибутные вызовы переведены на движковый уровень (`GreSetAttributes`/`GreGetAttributes`) с голыми бандлами. Контейнер `pAttrs` — `LINEBUNDLE`, `CHARBUNDLE`, `MARKERBUNDLE`, `AREABUNDLE`, `IMAGEBUNDLE`. Порядок аргументов Set: `(hdc, prim, flDefsMask, flAttrsMask, pAttrs)` корректен.

**A2 (опционально):** `#define INCL_DDIBUNDLES` в `goca_parser.hpp` можно удалить — типы `D*BUNDLE` больше не используются.

---

## B. Возврат `GreGetAttributes` — **ЗАВЕРШЕНО**

`GocaPushAttr` сохраняет маску дефолтов из возврата `GreGetAttributes` (или 0 при `GPI_ALTERROR`). `GocaPop` передаёт её в третий аргумент `GreSetAttributes` (`flDefsMask`). Для атрибутов, бывших = default, поля бандла не читаются — движок подставит default сам.

## C. Функциональные дефекты обработчиков

### C1. Заданная точка GFARC — **ЗАВЕРШЕНО**

`DoFullArc` читает центр для GFARC, устанавливает CP через `GreSetCurrentPosition`, вызывает `GreFullArcBoundary` (line primitive).

### C2. Заданная точка GPARC — **НЕ ВЫПОЛНЕНО**

| Ордер | Что в коде | Должно |
|---|---|---|
| **GPARC (0xE3)** | `if (!bCur) off += pointSize;` — начальная точка пропущена. `GrePartialArc` рисует линию от текущего CP. | AFPC p. 119: линия от (XPOS,YPOS) до начала дуги. Требуется `GreSetCurrentPosition` перед `GrePartialArc`. |
| **GCPARC (0xA3)** | Аналогично, но для GCPARC линия от текущего CP — корректно. | — |

**Дополнительные дефекты `DoPartialArc`:**

| № | Дефект | Основание |
|---|---|---|
| P1 | `multSize = (coordSize == SHORT) ? 2 : 4` — для BYTE даёт 4 (неверно) | `GocaGetMult`: BYTE = 2 байта |
| P2 | Проверка `len < off + ...` — минимум вместо точного `!=` | AFPC p. 119: точные длины |
| P3 | Ручное чтение мультипликатора вместо `GocaGetMult` | Дублирование кода |
| P4 | Углы `rawStart`/`rawSweep` читаются как `ULONG`, знак теряется | AFPC p. 120: EC-E302 (negative SWEEP), EC-E303 (negative START) |
| P5 | Нет проверки отрицательных углов | EC-E302, EC-E303 |

### C3–C5. Текущая позиция — **НЕ ВЫПОЛНЕНО**

| Ордер | Дефект | Основание |
|---|---|---|
| **GCCHST (0x83)** | `GreSetCurrentPosition` + `GreCharString` сдвигают CP | AFPC p. 92: CP **unchanged** |
| **GCHST (0xC3)** | `if (cch == 0) return GOCA_OK;` — до установки CP | AFPC p. 93: «serves only to move the current position» |
| **GCBOX (0x80)** | CP не восстанавливается после `GreBox*` | AFPC p. 91: CP **unchanged** |

### C14. Длины — минимум вместо точного набора — **НЕ ВЫПОЛНЕНО**

| Ордер | Проверка в коде | Range по AFPC | Стр. |
|---|---|---|---|
| GSCP | `!= 2*coordSize` ✓ | 4 | 143 |
| GSAP | `< 4*paramSize` | 8 | 130 |
| GSFLW | `< 2` | 2 | 147 |
| GSECOL | `< 2` | 2 | 146 |
| GSPRP | `< 2+pointSize` | 6 | 157 |
| GCFARC / GFARC | `!= multSize` / `!= pointSize+multSize` ✓ | 2 / 6 | 107 |
| GCPARC / GPARC | `< off+pointSize+multSize+8` | 14 / 18 | 119 |
| GBOX / GCBOX | `< 2+2*pointSize` / `< 2+pointSize` | 10,12,14 / 6,8,10 | 90 |
| GSCC | произвольные комбинации `rem` | 4, 8 | 134 |
| GSMC | 4 или 6 ✓ | 4, 6 | 152 |

В PM длины масштабируются `coordSize`; поля flags/res в GSCC/GSMC — расширение PM, отсутствующее в AFP.

### C15–C18. Семантика атрибутов — **НЕ ВЫПОЛНЕНО**

| № | Дефект | Основание |
|---|---|---|
| C15 | `GSLW`/`GSFLW` пишут `lb.lGeomWidth` и передают `LBB_WIDTH\|LBB_GEOM_WIDTH`. Геометрическая ширина — отдельный атрибут, ордер `GSSLW` (0x15). Маски Push правятся синхронно | p. 151/147; pmord.h `ORDERS_GSSLW` |
| C16 | `GSMC`: `bZero = (cx == 0 && cy == 0)` | p. 152: «if **either or both** of CELLWI or CELLHI are X'0000'» → `\|\|` |

### C19. Таблица цветов GOCA ≠ GPI — **НЕ ВЫПОЛНЕНО**

AFPC Table 5 (p. 15) против `pmgpi.h CLR_*`:

| GOCA | Цвет | GPI при том же числе | Требуется |
|---|---|---|---|
| 0000 / FF00 | drawing default | 0 = CLR_BACKGROUND | `flDefsMask` |
| 0001–0006 | Blue…Yellow | 1–6 ✓ | — |
| 0007 | White | 7 = CLR_NEUTRAL | `CLR_WHITE` (−2) |
| 0008 | Black | 8 = CLR_DARKGRAY | `CLR_BLACK` (−1) |
| 0009 | Dark blue | 9 ✓ | — |
| 000A | Orange | 10 = CLR_DARKRED | нет константы |
| 000B | Purple | 11 = CLR_DARKPINK | ≈ |
| 000C / 000D | Dark green / turquoise | 12 / 13 ✓ | — |
| 000E | Mustard | 14 = CLR_BROWN | нет константы |
| 000F | Gray | 15 = CLR_PALEGRAY | нет константы |
| 0010 (=16) | Brown | индекса 16 нет | нет константы |
| FF07 | device default | 7 ✓ | `CLR_NEUTRAL` |
| FF08 | color of medium | 8 ✗ | `CLR_BACKGROUND` (0) |

**GSCOL байт 0x07 ≠ GSECOL 0x0007.** Первый префиксуется X'FF' → FF07 (device default), второй → White. Код обрабатывает одинаково.

### C20–C21. Набор примитивов в shorthand — **НЕ ВЫПОЛНЕНО**

| Ордер | AFP набор | Сейчас |
|---|---|---|
| GSCOL / GSECOL / GSMX | 5: char, image, line, marker, pattern (p. 142/146/156) | 4 — **image отсутствует** |
| GSBMX | 4: char, image, marker, pattern (p. 132) | 4, но **включает line**, image отсутствует |

Push кладёт `IBB_*` → асимметрия Push/Set.

### C22–C26. Прочее — **НЕ ВЫПОЛНЕНО**

| Ордер | Дефект |
|---|---|
| **DoRelativeLine** | Накопление `x = (SHORT)(x + dx)` — при `coordSize == LONG` теряется разрядность; EC-E100 не проверяется |
| **DoBox** | `p[2]` читается как PM-флаги (0x40 fill / 0x20 boundary). В AFP поле RES = `X'2000'` (p. 90) → `p[2]=0x20` ошибочно принимается за BOUNDARY. HAXIS/VAXIS вне 0–32767 не проверяются (EC-C000/C001) |
| **DoPartialArc** | Отрицательные START/SWEEP не проверяются (EC-E302/E303, p. 120); при `coordSize == BYTE` берётся 4-байтный множитель — формат не определён |
| **DoVLongCharString** | `fl = CHS_START_XY` — `GCCHSTE_UNDERSCORE` (0x08) → `CHS_UNDERSCORE` (0x0200) и `STRIKEOUT` (0x04) → `CHS_STRIKEOUT` (0x0400) **теряются**; `CHS_VECTOR` не выставляется при наличии `adx`; `DosAllocMem` вместо фиксированного буфера |
| **DoGSCP** | Параметр `BOOL bPush` в теле не используется — Push делается в диспетчере через `GocaPushCurPos` |

## Решения, нужные до кода

1. **Цвета без констант GPI** (Orange, Purple, Mustard, Gray, Brown): RGB-режим логической таблицы (`GreCreateLogColorTable`, `LCOLF_RGB`), ближайший индекс или собственное отображение.
2. **`adx`** — фиксированный буфер с ограничением `cch` либо сохранение динамического выделения.
3. **`DoBox`** — флаги PM (0x40/0x20) против AFP RES=X'2000': разделение по диалекту или единая трактовка PM.
4. **EC-0002** — репортировать (PM) или игнорировать (AFP 4-я ред.).
