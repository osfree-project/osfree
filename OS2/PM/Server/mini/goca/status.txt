# Аудит и план работ GOCA-парсера

Диалект: **FULL GOCA (PM)**. Поддерживаются все варианты coordsize (BYTE, SHORT, LONG), BE/LE
AFPC-0008-03 — ПОДМНОЖЕСТВО FULL GOCA, только BE/SHORT
GDDM — подмножество FULL GOCA, только BYTE/SHORT, BE

## A. Смешанный контракт GRE — **ЗАВЕРШЕНО**

Все атрибутные вызовы на движковом уровне (`GreSetAttributes`/`GreGetAttributes`) с голыми бандлами. `GreDevice*Attributes` в `goca_parser.cpp` отсутствуют.

**Правило установки drawing default (EDM2 `GreSetAttributes`):**
> «Attributes whose flags are set in **both** flDefsMask and flAttrsMask are set to their default values.»
> «Attributes whose flags are set **only in flDefsMask** … are unchanged.»
> «Attributes whose flags are set only in flAttrsMask are set to the value specified by pAttrs.»

Следствие: для перевода атрибута в default бит маски обязан присутствовать одновременно в третьем и четвёртом аргументах.

**A2.** `#define INCL_DDIBUNDLES` в `goca_parser.hpp` закомментирован.

---

## B. Возврат `GreGetAttributes` — **ЗАВЕРШЕНО**

`GocaPushAttr`: `lDefs = GreGetAttributes(...)`, `e->usXxxDefs = (lDefs == GPI_ALTERROR) ? 0 : (USHORT)(lDefs & usXxx)`.
`GocaPop`: третий аргумент = `(ULONG)e->usXxxDefs`, четвёртый = `(ULONG)e->usXxx`. Для атрибутов, бывших = default, движок подставит актуальный default сам.

## C. Функциональные дефекты обработчиков

### C1. Заданная точка GFARC — **ЗАВЕРШЕНО**

`DoFullArc` читает центр для GFARC, устанавливает CP, вызывает `GreFullArcBoundary` (line primitive, а не area).

### C2. Заданная точка GPARC — **ВЫПОЛНЕНО ЧАСТИЧНО**

| Дефект | Статус |
|---|---|
| Пропуск начальной точки GPARC | **Исправлено** (`GreSetCurrentPosition`) |
| `multSize` для BYTE давал 4 | **Исправлено** (`LONG ? 4 : 2`) |
| Проверка `<` вместо `!=` | **Исправлено** (`expectedLen`) |
| Ручное чтение мультипликатора | **Исправлено** (`GocaGetMult`) |
| Углы как `ULONG`, знак терялся | **Исправлено** (знаковый `LONG`) |
| Нет проверки отрицательных углов | **Исправлено** (`GOCA_EC_PARC_NEGATIVE_START`/`_SWEEP`) |

### C3–C5. Текущая позиция — **НЕ ВЫПОЛНЕНО**

| Ордер | Дефект | Основание |
|---|---|---|
| **GCCHST (0x83)** | `GreSetCurrentPosition` вызывается безусловно после ветвления, включая `bCur == TRUE` | AFPC p. 92: CP **unchanged** |
| **GCHST (0xC3)** | `if (cch == 0) return GOCA_OK;` стоит **до** `GreSetCurrentPosition` | AFPC p. 93: «serves only to move the current position» |
| **GCBOX (0x80)** | CP не восстанавливается после `GreBox*` | AFPC p. 91: «unchanged (GCBOX)» |

### C6. Пустые и минимальные операнды — **ЧАСТИЧНО**

| Ордер | Сейчас | Должно | Статус |
|---|---|---|---|
| **GMRK** 1 точка | `nPts--` → 0, `cPoints=1` | 1 маркер в P0 | ✓ |
| **GCMRK** `len==0` | `nPts=0`, `cPoints=1` | 1 маркер в CP | ✓ |
| **GCLINE** `len==0` | `GrePolyLine(...,0)` — No-Op | No-Op | ✓ |
| **GLINE** `len==pointSize` | `GreSetCurrentPosition` + `nPts--`→0 | только переместить CP | ✓ |
| **GCRLINE** `len==0` | EC-0003 | No-Op | ✗ |
| **GRLINE** `len==pointSize` | `nTotal=1`, `GrePolyLine(aptl,1)` | только переместить CP | ✗ |
| **GCCBEZ** `len==0` | EC-0003 | No-Op | ✗ |
| **GCBEZ** 1 точка | EC-0003 | только переместить CP | ✗ |
| **GBEZ** 1 точка | EC-0003 | только переместить CP | ✗ |
| **GCFLT** `len==0` | EC-0003 | No-Op | ✗ |
| **GFLT** 1 точка | EC-0003 | только переместить CP | ✗ |
| **GCBEZ/GCCBEZ** | нет проверки 3m+1 | EC-0003 | ✗ |

### C14. Длины — **ЧАСТИЧНО**

| Ордер | Проверка | Статус |
|---|---|---|
| GSCP | `!= 2*coordSize` | ✓ |
| GSAP | `!= 4*paramSize` | ✓ |
| GSFLW | `!= 2` | ✓ |
| GCFARC / GFARC | `!= multSize` / `!= pointSize+multSize` | ✓ |
| GCPARC / GPARC | `!= expectedLen` | ✓ |
| GSCC | строгие формы, `rem != 0` | ✓ |
| GSMC | строгие формы, `rem != 0` | ✓ |
| GPOP | `p[1] != 0` | ✓ |
| GSECOL | `< 2` | ✗ |

| GBOX | `< 2`, затем `< 2+2*pointSize`; оси без контроля остатка | ✗ |
| GCBOX | `< 2`, затем `< 2+pointSize`; оси без контроля остатка | ✗ |
| GBEZ/GCBEZ/GFLT/GCFLT | кратность + минимум; нет 3m+1 | ✗ |

### C15. Геометрическая ширина — **ЗАВЕРШЕНО**

`GSLW`/`GSFLW`: только `lb.fxWidth`, маска `LBB_WIDTH`. `lGeomWidth` удалён. Геометрическая ширина — отдельный атрибут `GSSLW` (0x15), не реализован (D10).

### C16–C18. Семантика атрибутов — **НЕ ВЫПОЛНЕНО**

| № | Дефект | Основание |
|---|---|---|
| C16 | `bZero = (cx == 0 && cy == 0)` | AFPC p. 152: «if **either or both** of CELLWI or CELLHI are X'0000'» → `\|\|`. При `cx==0, cy!=0` ветка `else` запишет `(0, cy)` вместо `(0,0)` |
| C17 | `GSPRP_DEFAULT` → `pt.x=0; pt.y=0` | AFPC p. 157: drawing default. Нужен `flDefsMask = ABB_REF_POINT` в обеих масках |
| C18 | `GreGetDefaultAttributes(PRIM_CHAR, CBB_BOX)` | Фиксирует снимок дефолта. Нужен `flDefsMask = CBB_BOX`, вызов удалить |

### C19. Таблица цветов — **НЕ ВЫПОЛНЕНО**

| Значение | Сейчас | Требуется |
|---|---|---|
| 0000 / FF00 | дословно в бандл | `flDefsMask` |
| 0007 | 7 | `CLR_WHITE` (−2) |
| 0008 | 8 | `CLR_BLACK` (−1) |
| FF07 | 7 | `CLR_NEUTRAL` |
| FF08 | 8 | `CLR_BACKGROUND` (0) |
| 000A, 000B, 000E, 000F, 0010 | нет констант | решение 1 |

**GSCOL байт 0x07 ≠ GSECOL 0x0007.** Первый → FF07 (device default), второй → White. Код обрабатывает одинаково.

### C20–C21. Набор примитивов в shorthand — **НЕ ВЫПОЛНЕНО**

| Ордер | Сейчас | Должно |
|---|---|---|
| GSCOL / GSECOL / GSMX | 4 примитива | 5: + `PRIM_IMAGE` |
| GSBMX | 4 примитива, включает `PRIM_LINE` | 4: char, image, marker, pattern (без line) |

### C22–C28. Прочее — **НЕ ВЫПОЛНЕНО**

| № | Дефект |
|---|---|
| C22 | `DoRelativeLine`: `SHORT x, y`, потеря разрядности при LONG |
| C23 | `DoBox`: `p[2]` как PM-флаги; AFP RES=X'2000'; HAXIS/VAXIS вне 0–32767 |
| C25 | `DoVLongCharString`: UNDERSCORE/STRIKEOUT теряются; `CHS_VECTOR`; `DosAllocMem`; `cch==0` → DRAWRECT не выполняется |
| C26 | `DoGSCP`: `bPush` не используется |
| C27 | Обводка дуги/бокса безусловна, не подчинена `BA_BOUNDARY` |
| C28 | Коды возврата `Gre*` не проверяются |

## Решения, нужные до кода

1. **Цвета без констант** (Orange, Purple, Mustard, Gray, Brown): RGB-режим логической таблицы (`GreCreateLogColorTable`, `LCOLF_RGB`), ближайший индекс или собственное отображение.
2. **`adx`** — фиксированный буфер с ограничением `cch` либо сохранение `DosAllocMem`.
3. **`DoBox`** — флаги PM (0x40/0x20) против AFP RES=X'2000': разделение по диалекту или единая трактовка. Поведение при сброшенных обоих битах.
4. **`GBOX` CP** — контракт `GreBox*` по CP из `pmddim.h`: `GreBox*` использует CP как первый угол. Для GBOX CP устанавливается в (XPOS0, YPOS0) до вызова. Для GCBOX CP уже на месте — не трогать.
5. **`GCHSTE` при `cch==0`** — зафиксировано: ранний возврат до DRAWRECT/LEAVEPOS. Если рамка должна рисоваться при пустой строке — пересмотреть.
6. **Стандартное действие** — `GocaEcIsRetired` + `GocaEcHasStandardAction` из `F_gocaerr.h` не применяются в `GocaParseStream`. Фатальный выход по любому `rc != GOCA_OK`. Требуется решение: для retired-кодов — логировать и пропустить; для кодов со стандартным действием — выполнить действие и продолжить; для drawing process checks — остановиться.
7. **`GSCC` `bZero`** — четыре компонента через `&&`. Нужно ли «либо/оба» как в `GSMC`, или все четыре? По `pmord.h` `ORDERS_GSCC` содержит `SHORT cxInt, cyInt` + `USHORT cxFract, cyFract` — дробная часть дополняет целую, ноль в целой при ненулевой дробной ≠ ноль ячейки. Оставить `&&` по четырём компонентам.
