### 1.5 Инварианты

1. **Sidecar — raw tag-value.** `<file>.license` содержит `SPDX-License-Identifier:` без comment marker. Читается `ReuseQueryFileTags` с `hStyle == NULLHANDLE` (offset = 0).
2. **In-file — только через style.** Если `ReuseQueryCommentStyle` вернул `fFound == FALSE`, in-file теги прочитать нельзя → `REUSE_ERROR_NO_COMMENT_STYLE`.
3. **Дерево без `comments.toml`** — `ReuseOpenTree(pszDir, NULL, …)` возвращает `REUSE_ERROR_NO_COMMENT_STYLE`, дерево не открывается. Fatal.
4. **`REUSE-IgnoreStart`/`REUSE-IgnoreEnd`** — REUSE-домен, обрабатывается в `reuse_tags.c` до `SpdxQueryTagLine`.
5. **`REUSE.toml`/DEP5** — не зависят от comment style. Работают всегда, когда открыто дерево.
6. **`--comments-config`** — обязателен для всех трёх приложений (P1/P2/P3a).
7. **`REUSE_ERROR_NO_COMMENT_STYLE`** — фатален. Два источника (`ReuseOpenTree`, `ReuseOpenFile`), два разных сообщения в приложениях.
8. **`SPDXSNIPPET`, `SPDXSNIPPETLIST`** — типы REUSE-слоя, объявлены в `reuse.h`. `SpdxSnippetListInit/Free` перенесены из `spdx_tag.c` как `ReuseSnippetListInit/Free` в `reuse_tags.c`.
9. **`ReuseQueryFileTags`** — единственный читатель in-file и sidecar; вызывается только из `reuse.c::resolve_file`.
10. **`ReuseQueryCommentBlock`** требует `pszSingleLine` для single-line вывода. `pszSingleLineRegexp` — только для чтения. Оба поля могут сосуществовать.
11. **`shebangs`** — не «обязательная первая строка», а «если первая строка совпадает с одной из записей, оставить на строке 1, теги вставить после». Не совпало → теги на строку 1.
12. **`ReuseQueryCommentBody`** при совпадении `multi_start`/`multi_middle` обрезает trailing `multi_end` прямо в `pszLine` (in place). Сигнатура `PSZ`, не `PCSZ`.

### 2.2 Соглашения

- Все публичные функции — `APIENTRY`, возвращают `APIRET`.
- Выходные строки — size-query convention: `pszBuf == NULL && ulSize == 0` → только `*pulUsed` (размер с NUL); иначе копирование с NUL; если буфер мал — `ERROR_BUFFER_OVERFLOW`, `*pulUsed = required`.
- Глаголы: `Open`, `Close`, `Query`, `Get`, `Create`. `Resolve` — не из IBM-таблицы, не используется в публичном API.
- `Tree` в именах публичных функций — контекст, не объект. Убран из `resolve_file`/`FileClose`/`FileGet*` (P1); `ReuseQueryTree*` и `ReuseTreeGetError*` остались как есть (не менялись).
- Handles — `HANDLE` (указатель с magic внутри). `NULLHANDLE` = `0`.

### 2.3 `spdx_tag.h` — SPDX tag-value parser

**После P5** содержит только:
- `SPDXTAG` enum (Clause 6–13, Annex E, Annex H, Annex H.3);
- `SPDXTAGINFO` struct;
- `SPDX_TAG_ERROR_SYNTAX` (0xFF01);
- `SpdxQueryTagLine(pszLine, pTag, pfDeprecated, pfInFileForm, pszValue, ulSize, pulUsed)` — 7 аргументов;
- `SpdxQueryTagInfo(tag, pInfo)`.

**Не содержит** (перенесено в `reuse.h` в P5):
- `SPDXSNIPPET`, `SPDXSNIPPETLIST`, `PSPDXSNIPPET`, `PSPDXSNIPPETLIST`;
- `SpdxSnippetListInit`, `SpdxSnippetListFree`;
- `SpdxQueryFileHasTag`, `SpdxQueryFileLicense`, `SpdxQueryFileCopyright`, `SpdxQueryFileSnippets`;
- `skip_comment_prefix`, `line_ignore_marker`, `line_starts_with_tag`, `tag_value`, `strip_trailing_markers`, `append_line`, `snippetlist_add`.

`SpdxQueryTagLine`:
- Распознаёт canonical Clause 6–13, Annex E (`SPDX-License-Identifier:`), Annex H (`SPDX-<Clause 8 field>:`), Annex H.3 (`SPDX-SnippetBegin`/`End`, `SPDX-<Clause 9 field>:`).
- `pfInFileForm = TRUE` для форм с префиксом `SPDX-`; FALSE для canonical Clause 6–13 / `SPDXTAG_NONE` / `SPDXTAG_OTHER`.
- BOM (`EF BB BF`) на начале строки пропускается.
- size-query convention для `pszValue`.

`SpdxQueryTagInfo` возвращает **каноническую** форму (Clause 8.8 `FileCopyrightText:` для `SPDXTAG_COPYRIGHT`), независимо от того, какая форма была в файле.

### 2.5 `reuse_comments.c` — API

**`REUSECOMMENTSTYLEINFO`:**

```c
    BOOL fMultiLine;
```

**Внутренняя `REUSECOMMENTSTYLE`** (в `reuse_comments.c`):
```c
typedef struct _REUSECOMMENTSTYLE {
    ULONG ulMagic;
    PSZ   pszName;
    PSZ   pszSingleLine;           /* literal для записи */
    PSZ   pszSingleLineRegexp;     /* паттерн для чтения */
    PSZ   pszIndentAfterSingle;
    PSZ   pszMultiStart;
    PSZ   pszMultiMiddle;
    PSZ   pszMultiEnd;
```

`pszSingleLine` и `pszSingleLineRegexp` **могут сосуществовать**. При чтении (`ReuseQueryCommentBody`) сначала пробуется regexp, затем literal. При записи (`ReuseQueryCommentBlock`) используется `pszSingleLine`. Если `pszSingleLine == NULL` — только multi-line запись.

**`ReuseQueryCommentBody`:** в `pszLine` — in place — при совпадении `multi_start`/`multi_middle` обрезает trailing `multi_end` (см. §1.5 п.12).

### 2.6 `comments.toml` — фактическое содержимое

**`[[map]]` (34):**

- `*.cmd/bat/btm` → `batch`
- `Makefile/makefile` → `hash`
- `*.sh/py/pl/rb/toml/yml/yaml` → `hash`

- `*.bib` → `bibtex`

**Синтаксис `single_line_regexp`** (минимальный, реализован в `reuse_comments.c`):

| Элемент | Значение |
|---|---|
| `^` | Анкор в начале (no-op: match всегда с начала) |
| `.` | Любой символ, кроме `\0` |
| `[...]`, `[^...]`, `[!...]` | Класс символов, с диапазонами `a-z` |
| `*`, `+`, `?` | 0+, 1+, 0-1 предыдущего атома |
| `\b` | Граница слова (zero-width) |
| `\X` | Литерал X (в т.ч. `\\`, `\.`, `\*`) |
| Остальное | Литерал |

Не поддерживается: `$`, `{n,m}`, `|`, `()`, backreferences, lookaround.

**Семантика `shebangs`:** если первая строка файла совпадает с одной из записей — оставить её на строке 1, теги вставить после. Не совпало → теги на строку 1. `@echo off` и `echo off` — в `shebangs` у `batch`; `#!` — у `hash`, `c`, `julia`, `tex`; `<?xml` — у `html`; и т.д.

**Замечания к данным (не блокируют):**
1. `cppsingle` объявлен, но не используется ни в одном `[[map]]` — dead entry.
2. `shebangs = ["<?php"]` у стиля `c` — без `*.php` в `[[map]]`.
3. `*.txt`, `*.ini`, `*.cfg`, `*.conf`, `*.mk`, `*.asm`, `*.inc` — нет `[[map]]` → `REUSE_ERROR_NO_COMMENT_STYLE` в `reuse-lint`/`reuse-annotate`/`spdx-sbom` (осознанный sidecar-only, если пользователь не добавит `[[map]]`).
4. `apszBinaryExt` в старом `reuse-annotate` содержал ~20 расширений (`.bmp`, `.jpeg`, `.sys`, `.zip`, `.pdf`, …) — в `[[map]]` только 9. После P8 эти расширения без `[[map]]` → `no [[map]] entry` в `reuse-annotate`.

### 2.14 Обработка `REUSE_ERROR_NO_COMMENT_STYLE` — два источника
